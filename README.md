# PDF Reader Finance

A fast PDF reader and editor for Windows and Mac: read, search, highlight, comment, type on pages, compare two
versions of a document, redact, organize pages, recognize scanned text, export tables to Excel, fill in forms
and sign.

## Download

**[Get the newest version](https://github.com/kohirschmann/pdf-reader-finance/releases/latest)** and pick the
file for your computer:

| Computer | Download |
| --- | --- |
| Windows PC, Intel or AMD (also runs on ARM PCs) | `PDF-Reader-Finance-Setup-<version>-x64.exe` |
| Mac with Apple silicon (M1 or newer) | `PDF-Reader-Finance-<version>-mac-arm64.dmg` |
| Mac with an Intel processor | `PDF-Reader-Finance-<version>-mac-intel.dmg` |

**Windows:** open the setup. If "Windows protected your PC" appears, click More info › Run anyway. It installs
for your Windows account only; no administrator rights are needed.

**Mac** (macOS 14 Sonoma or newer): open the disk image and drag the app into Applications. Because it isn't
from the App Store, macOS asks once: open it, then go to System Settings › Privacy & Security and click
**Open Anyway**.

## Updates

In the app, **Help › Check for Updates…** looks here for a newer version and installs it. Your settings,
signature and recent files stay.
